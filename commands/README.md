# Useful SSH & shell commands

Handy commands and shell helpers we use day-to-day at TPN Labs. Each command lives in its own file in this folder.

## Setup

Copy the function(s) you want into your `~/.zshrc` (or `~/.bashrc`), then reload your shell:

```sh
source ~/.zshrc
```

## Commands

| Command | What it does |
| --- | --- |
| [`git-gone`](git-gone.md) | Prunes local branches whose upstream branch was deleted on the remote (e.g. after a merged PR) |
